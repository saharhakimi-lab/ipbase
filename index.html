מהי כתובת IP גרסה 4?

כתובת IP IPv4 היא מזהה ייחודי של מכשיר ברשת. היא מורכבת מ-32 סיביות Bits המחולקות ל-4 אוקטטות בנות 8 ביטים כל אחת.

חלוקת הכתובת לשני חלקים:

  • מזהה הרשת Net ID: מזהה את הרשת המקומית.
  • מזהה המארח Host ID: מזהה את המכשיר הספציפי ברשת.
מבנה כתובת IPv4 דוגמה עבור Class C עם /24
אוקטטה 1 192 11000000
אוקטטה 2 168 10101000
אוקטטה 3 1 00000001
אוקטטה 4 10 00001010

כתובת IP ציבורית מול פרטית

טווחי הכתובות הפרטיות לפי תקן RFC 1918

Class A: 10.0.0.0 – 10.255.255.255
Class B: 172.16.0.0 – 172.31.255.255
Class C: 192.168.0.0 – 192.168.255.255

מחלקות של כתובות IP

מחלקה טווח אוקטטה ראשונה מסכת ברירת מחדל / פרפיקס שימוש ייעודי
Class A 1 – 127 255.0.0.0 /8 ארגונים ענקיים
Class B 128 – 191 255.255.0.0 /16 ארגונים בינוניים
Class C 192 – 223 255.255.255.0 /24 רשתות קטנות וביתיות
Class D 224 – 239 — שידורי מולטיקאסט Multicast

ניתוח סוגי כתובות IP וכתובות מיוחדות

בעולם הרשתות, לכל כתובת IP יש תפקיד מוגדר. חלקן מיועדות לתקשורת ברשת המקומית, חלקן לאינטרנט, וחלקן שמורות לתפקידים מערכתיים מיוחדים.

🔴 כתובות פרטיות מול ציבוריות

כתובת פרטית: מיועדת לשימוש פנימי בתוך הבית או המשרד. לא ניתנת לניתוב באינטרנט הציבורי.
כתובת ציבורית: כתובת ייחודית בעולם כולו, המוקצית על ידי ספק האינטרנט ISP.

🔴 כתובת רשת Network ושידור Broadcast

כתובת רשת: הכתובת הראשונה במתחם הרשת (כל ביטי ה-Host הם 0).
כתובת ברודקאסט: הכתובת האחרונה במתחם (כל ביטי ה-Host הם 1).

🔴 כתובת חירום APIPA

כאשר מחשב לא מצליח להשיג כתובת משרת DHCP, מערכת ההפעלה מקצה לעצמה כתובת חירום בטווח: 169.254.0.1 – 169.254.255.254.

🔴 כתובת לולאה פנימית Loopback

כתובת בדיקה עצמית פנימית של כרטיס הרשת Localhost. הכתובת הנפוצה לבדיקה: 127.0.0.1.

ייצוג בינארי ותיאוריית בסיסי הספירה

מחשבים ורכיבי תקשורת מעבדים נתונים בבסיס בינארי (בסיס 2) המורכב מהספרות 0 ו-1 בלבד.
