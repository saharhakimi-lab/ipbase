■ מהי כתובת IP (גרסה 4)?

כתובת IP (IPv4) היא מזהה ייחודי של מכשיר ברשת. היא מורכבת מ-32 סיביות (Bits) המחולקות ל-4 אוקטטות בנות 8 ביטים כל אחת.

חלוקת הכתובת לשני חלקים:
  • מזהה הרשת (Net ID): מזהה את הרשת המקומית.
  • מזהה המארח (Host ID): מזהה את המכשיר הספציפי ברשת.

מבנה כתובת IPv4 (דוגמה עבור Class C עם /24)

אוקטטה 1 192 11000000
אוקטטה 2 168 10101000
אוקטטה 3 1 00000001
אוקטטה 4 10 00001010
← Net ID (24 Bits) Host ID (8 Bits) →

■ כתובת IP ציבורית מול פרטית

טווחי הכתובות הפרטיות לפי תקן RFC 1918

Class A 10.0.0.0 – 10.255.255.255
Class B 172.16.0.0 – 172.31.255.255
Class C 192.168.0.0 – 192.168.255.255

מחלקות של כתובות IP

מחלקה טווח אוקטטה ראשונה מסכת ברירת מחדל / פרפיקס שימוש ייעודי
Class A 1 – 127 255.0.0.0 (/8) ארגונים ענקיים
Class B 128 – 191 255.255.0.0 (/16) ארגונים בינוניים
Class C 192 – 223 255.255.255.0 (/24) רשתות קטנות וביתיות
Class D 224 – 239 — שידורי מולטיקאסט (Multicast)

🔴 ניתוח סוגי כתובות IP וכתובות מיוחדות

בעולם הרשתות, לכל כתובת IP יש תפקיד מוגדר. חלקן מיועדות לתקשורת ברשת המקומית, חלקן לאינטרנט, וחלקן שמורות לתפקידים מערכתיים מיוחדים.

🔴 כתובות פרטיות מול ציבוריות

  • כתובת פרטית (Private IP): מיועדת לשימוש פנימי בתוך הבית או המשרד. לא ניתנת לניתוב באינטרנט הציבורי.
  • כתובת ציבורית (Public IP): כתובת ייחודית בעולם כולו, המוקצית על ידי ספק האינטרנט (ISP) ומאפשרת גישה ישירה לרשת הגלובלית.
טווחי הכתובות הפרטיות לפי תקן RFC 1918:
Class A: 10.0.0.0 – 10.255.255.255 (/8)
Class B: 172.16.0.0 – 172.31.255.255 (/16)
Class C: 192.168.0.0 – 192.168.255.255 (/24)

🔴 כתובת רשת (Network) ושידור (Broadcast)

  • כתובת רשת (Network ID): הכתובת הראשונה במתחם הרשת (כל ביטי ה-Host הם 0). מייצגת את הרשת כולה ולא ניתנת להקצאה למחשב.
  • כתובת ברודקאסט (Broadcast): הכתובת האחרונה במתחם (כל ביטי ה-Host הם 1). משמשת לשליחת הודעה לכל המכשירים ברשת בו-זמנית.

🔴 כתובת חירום APIPA

כאשר מחשב מוגדר לקבל IP אוטומטית משרת DHCP אך השרת אינו זמין, מערכת ההפעלה מקצה לעצמה כתובת חירום אוטומטית.

טווח הכתובות השמור: 169.254.0.1 – 169.254.255.254

🔴 כתובת לולאה פנימית (Loopback)

כתובת בדיקה עצמית פנימית של כרטיס הרשת (תקשורת Localhost). התנועה לא יוצאת לכבל הרשת אלא חוזרת חזרה לרכיבי התוכנה של המחשב.

כתובת בדיקה נפוצה (טווח 127.0.0.0/8): 127.0.0.1 (Localhost)

🔴 שידור קבוצתי (Multicast)

בשונה מ-Unicast (מכשיר מול מכשיר) או Broadcast (מכשיר מול כולם), כתובות Multicast מאפשרות לשלוח חבילת מידע בודדת מקור אחד אל קבוצת מנויים מוגדרת בלבד (כגון שידורי וידאו חי, פרוטוקולי ניתוב EIGRP/OSPF ועוד). הטווח השמור הוא מחלקה Class D: 224.0.0.0 – 239.255.255.255.

■ ייצוג בינארי ותיאוריית בסיסי הספירה

מחשבים ורכיבי תקשורת מעבדים נתונים בבסיס בינארי (בסיס 2) המורכב מהספרות 0 ו-1 בלבד. כל אוקטטה מורכבת מ-8 ביטים, ומשקלם מוכפל ב-2 ככל שזזים שמאלה.

■ הבסיס ההקסדצימלי (Hexadecimal - Base 16)

בסיס 16 משמש בעיקר לייצוג מקוצר של כתובות MAC וכתובות IPv6. כל ספרה הקסדצימלית מייצגת בדיוק 4 ביטים (Nibble).

עשרוני (Decimal) 0123456789101112131415
הקסדצימלי (Hex) 0123456789 ABCDEF
